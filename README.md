# 🔧 FileConvert - Конвертер файлов

Бесплатный онлайн-сервис для конвертации изображений и работы с PDF.

## ✨ Возможности

- 🖼️ **Конвертер изображений** — PNG, JPG, WebP, AVIF, TIFF
- 📸 **Изображения → PDF** — объединение картинок в PDF
- 📑 **Объединение PDF** — склейка нескольких PDF в один
- 📦 **Сжатие PDF** — уменьшение размера файла

## 🚀 Установка

```bash
# Клонируй репозиторий
git clone https://github.com/bashnyaproject-oss/PDF.git
cd PDF

# Установи зависимости
npm install

# Запусти сервер
npm start
```

Открой http://localhost:3000

## 💰 Тарифы

| Тариф | Конвертаций/день | Макс. файл | Цена |
|-------|------------------|------------|------|
| Бесплатный | 5 | 10 МБ | 0 ₽ |
| Базовый | 50 | 50 МБ | 199 ₽/мес |
| Про | ∞ | 100 МБ | 499 ₽/мес |

## 🛠️ Технологии

- **Backend:** Node.js, Express
- **Изображения:** Sharp
- **PDF:** pdf-lib, pdf-merger-js
- **Сервер:** Nginx, PM2

## 📁 Структура

```
├── public/
│   └── index.html      # Фронтенд

├── ecosystem.config.js # PM2 конфиг
├── nginx.conf          # Nginx конфиг
└── deploy.sh           # Скрипт деплоя
```

## 🌐 Деплой

```bash

chmod +x deploy.sh

```
